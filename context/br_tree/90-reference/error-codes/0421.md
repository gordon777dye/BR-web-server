**Error:** 0421

**Description:** Debugger authentication failed

**Details:** Every failure of the debugger's authentication handshake, which BR 5.0 requires before a debugger may attach. The nine refusals in `debug.cpp` cover a cookie-mode check, a send or receive failure on the TLS connection, a malformed response packet, an HMAC that does not match (compared in constant time), and the operator pressing the break key while the handshake is in progress. The handshake is **mutual** - `DEBUG CONNECT` dials out to a host the operator names and then streams source, values and the whole log to it, so BR proves itself to the peer as well.

**Raised by:** `debug.cpp`
