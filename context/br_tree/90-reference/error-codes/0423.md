**Error:** 0423

**Description:** A debug observer is already attached

**Details:** `DEBUG OBSERVE <host>` while an observer is already attached. One observer at a time; `DEBUG OBSERVE OFF` releases the current one.

**Raised by:** `debug.cpp`
