**Error:** 0440

**Description:** MSG answer is not a number and the result variable is numeric

**Details:** The `MSG` action answered with something that is not a number while the result variable is numeric. It has a code of its own rather than reusing conversion error 2 because 2 would leave the variable untouched **and the action reporting success** - measured, by doing exactly that.

**Raised by:** `brmsg.cpp`
