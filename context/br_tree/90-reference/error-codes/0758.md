**Error:** 0758

**Description:** HTTP URL_BASE= is not in BR's current folder or below it

**Name:** `BREHTTPURLBASEOUTSIDE`

**Details:** `URL_BASE=` is turned into a full path, as written - relative parts and `..`
resolved, links not followed - and must be BR's working directory or a folder under it. A
junction or link on the way to it is allowed; links *inside* it that lead out are refused per
request with 403 instead.

**SYSERR$:** The full path of `URL_BASE=`, and the working directory, as
`<path> (current folder <folder>)`.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> The server serves files only from under BR's working directory, and only from `URL_BASE=`.

**Fix:** Put the site's files in a folder under the folder BR starts in, and point `URL_BASE=` at
it - or start BR in a folder that contains them. Use `URL_BASE=NONE` if BR serves no files.

Available as of BR! `5.02`.
