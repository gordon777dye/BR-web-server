**Error:** 0840

**Description:** Invalid `menu` indenting

**Details:** Sub menus are specified by the indenting the menu item text from the previous menu item. The number of spaces indented for the first indented item will determine the number of spaces per indent for the rest of the menu items.

**Not raised by `DISPLAY MENU` at present (BR 5.0 to 5.03).** The client answers `DISPLAY MENU` before it builds the menu, so a menu it cannot build is not reported: bad indentation, and arrays of different sizes, give no error, and the menu is left incomplete. Check a new menu by eye until this is fixed.

See also the `Display Menu` `command`.
