**Error:** 10023

**Description:** Too many sessions - maximum 9 sessions allowed

**Details:** Every one of the workstation ID's nine session slots is locked. BR may then move to another workstation ID and try again if it is configured to increment the WSID; if it is not, the session cannot start.

**Raised by:** `startup.cpp`, `wbserver.cpp`
