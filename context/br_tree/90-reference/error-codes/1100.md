**Error:** 1100

**Description:** Illegal multiple `statement` operations

**Details:** Illegal multi-statement operation.  BR! does not permit the use of `Data`, `Dim`, `Exit`, `Form` on the same program `line number` as any other statement. And it doesn't permit multiple `Option` statements in the same program. Place the offending instruction on its own program line.
