**Error:** 4151

**Description:** CLOSE DROP or FREE requires the file to be opened for output

**Details:** `CLOSE ,FREE` deletes the file and `CLOSE ,DROP` empties it, so BR 5.0 requires it to have been opened for output: a file opened for input is not yours to destroy. Only the cases that would really destroy something are refused - window-display files, asynchronous communications files and printer files are exempt.

**Raised by:** `bopen.cpp`
