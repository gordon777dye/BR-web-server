**Error:** 4153

**Description:** Restricted session: may not change a file this session did not create

**Details:** A restricted session may change only files **it created itself**. This is the refusal for one it did not, and it is logged as a security event naming the operation and the full path.

**Raised by:** `file_os.cpp`, `wbname.cpp`
