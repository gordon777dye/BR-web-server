**Error:** 4154

**Description:** Restricted session: this operation is not permitted

**Details:** The blanket refusal for an operation a restricted session may not perform at all. It is raised from ten places and so covers more than one kind of thing: a `MSG` action outside the eighteen permitted (`brmsg.cpp`), `SPAWN_RESTRICTED` and two other guarded functions (`numfunct.cpp`), a refused command (`command.cpp`, `command7.cpp`), a configuration directive (`config.cpp`), and printing and spooling operations (`printers.cpp`, `spool.cpp`). Every refusal is logged as a security event naming the operation.

**Raised by:** `brmsg.cpp`, `command.cpp`, `command7.cpp`, `commandc.cpp`, `config.cpp`, `numfunct.cpp`, `printers.cpp`, `spool.cpp`
