**Error:** 4155

**Description:** No session is free on this WSID for a restricted session

**Details:** `SPAWN_RESTRICTED` refuses when the count of sessions in use on the workstation ID has reached one less than the maximum: **one session is always kept free**, so a spawned session can never take the last one a person might need. With eight of the nine in use, this is raised and logged.

**Raised by:** `wbserver.cpp`
