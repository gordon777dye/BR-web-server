**Error:** 4156

**Description:** A restricted session can be started only from a local Windows session

**Details:** `SPAWN_RESTRICTED` is refused in **client/server mode**, and is compiled only into the Windows build. The reason is not a licence restriction: the child starts its own client, which in client/server mode would put a window on the *server* rather than in front of the person who asked for it.

**Raised by:** `wbserver.cpp`
