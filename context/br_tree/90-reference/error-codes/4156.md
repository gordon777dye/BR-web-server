**Error:** 4156

**Description:** A restricted session cannot be started from this session

**Details:** `SPAWN_RESTRICTED` needs a window to open the new session in, in front of the person who asked for it. It raises this from a **console client**, which has no second window to open, and in local mode on a platform BR cannot start one on (a Mac). The reason is not a licence restriction.

Before BR 5.03 this was also raised in every client/server session. From 5.03 the BR client starts the new session on the person's computer, so a client/server session with a windowed client can call `SPAWN_RESTRICTED`; see 4178 for when that start fails.

**Raised by:** `wbserver.cpp`, `term.cpp`
