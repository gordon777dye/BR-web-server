**Error:** 4157

**Description:** The restricted session did not finish in time and was ended

**Details:** The `wait` given to `SPAWN_RESTRICTED` ran out with the session still running, so it was ended. A disposable session nobody is waiting for has no reason to go on holding a session number and its restriction latch.

**Raised by:** `numfunct.cpp`
