**Error:** 4158

**Description:** No assistant is listening on this session's channel

**Details:** The `AI` command at the console had nothing to talk to: `agentChat(AGENTCHAT_ASK, …)` answered `AGENTCHAT_NO_AGENT`, meaning no assistant is connected to this session's channel.

**Raised by:** `commandc.cpp`
