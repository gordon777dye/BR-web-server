**Error:** 4161

**Description:** The assistant channel was closed after repeated bad handshakes

**Details:** A channel closed itself after too many consecutive failed attempts to attach - the debugger channel counts bad attaches, the assistant channel bad handshakes. The listener is shut and the token deleted, so there is nothing left to connect to and **the command must be given again**. The running program is handed the error so that it can decide what to do about a channel that has just been shut under it.

**Raised by:** `debug.cpp`, `harness.cpp`, `harness.h`
