**Error:** 4163

**Description:** No assistant connected to the channel in time and it has been closed

**Details:** A channel is published only while it is unclaimed. Nothing attached within the time allowed, so the channel was closed and its token removed. Before this it waited for ever, which left the token published for as long as the command sat there.

**Raised by:** `debug.cpp`, `harness.cpp`
