**Error:** 4164

**Description:** This session is in user mode and cannot change to DEVELOP mode

**Details:** DEVELOP mode is chosen when the channel is opened - the third argument to `MSG("harness", port, "DEVELOP")` - and nowhere else. A session that opened its channel in user mode cannot change its mind. The call also leaves the reason in the result string.

**Raised by:** `brmsg.cpp`
