**Error:** 4165

**Description:** Restricted session: brrestrict.sys does not permit this file

**Details:** The site's `brrestrict.sys` read list does not allow this file to a restricted session - either the list **excludes** it explicitly or it simply does not permit it, and the log says which. A file the session created itself is allowed whatever the list says, and is checked first.

**Raised by:** `file_os.cpp`
