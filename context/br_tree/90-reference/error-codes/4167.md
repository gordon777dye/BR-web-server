**Error:** 4167

**Description:** The operator did not permit this operation for the assistant

**Details:** Without a grant, a destructive operation inside an assistant's turn stops and asks the operator at the console. This is the answer when the operator says no. The question names the same verb the restricted session's refusals use - "to delete", "to open for output".

**Raised by:** `basic.h`, `commandc.cpp`
