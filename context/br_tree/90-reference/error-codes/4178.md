**Error:** 4178

**Description:** The restricted session did not start: its client did not log in and claim it in time

**Details:** In a client/server session `SPAWN_RESTRICTED` has the BR client start the new session as a second client, which connects through brlistener and logs in. This is raised when that has not happened within 60 seconds, or within the call's `wait` if that is shorter. Common causes: a login box was cancelled or not answered, the listener could not be reached, or the `wait` was too short for the new client to start. Nothing of the new session is left running; if its client arrives later, its server refuses to start.

**Raised by:** `wbserver.cpp`
