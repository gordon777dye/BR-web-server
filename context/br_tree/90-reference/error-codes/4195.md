**Error:** 4195

**Description:** Null record encountered. READ check for null bytes failed.

**Details:** Null record encountered 4194, 4195 and 4196 have the same meaning, but appear at different points within BR!.They denote that a network error has occurred that is serious and in essence stops all further processing.
