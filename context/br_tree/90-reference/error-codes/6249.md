**Error:** 6249

**Description:** Invalid NWP font specification

**Details:** The NWP font specification could not be parsed. Reported through the font diagnostic path, so whether it is seen depends on `CONFIG` font diagnostic level: this one is suppressed at level 3 or below.

**Raised by:** `printers.cpp`
