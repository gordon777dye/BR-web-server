**Error:** 6251

**Description:** Requested print font is not available, a substitute was used

**Details:** The requested print font is not available, so BR substituted one and carried on - **the print is not abandoned**. The diagnostic carries the detail `requested <face>, using <face>, at page <n> line <n>`, and is suppressed at font diagnostic level 2 or below.

**Raised by:** `printcontext.cpp`, `printers.cpp`
