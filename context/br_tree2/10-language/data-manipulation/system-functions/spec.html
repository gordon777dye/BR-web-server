System (built-in) functions

BR's intrinsic functions — they return a value and are used inside expressions. Grouped below by purpose. User-defined functions (DEF/FN) are a separate topic in flow-control/functions-udf.

Syntax

Most take the form NAME(args). A few system values take no parentheses: DATE$, DATE, TIME$, ERR, LINE, CNT, CODE, PROCIN, FILENUM, INF, PI, USERID$, LOGIN_NAME$, WSID$, SERIAL, SESSION$, PROCLVL, TIMER, VARIABLE$, WBVERSION$, WBPLATFORM$, SYSERR, SYSERR$, BRERR$, MENU$, CURPOS, NXTFLD, RND (and PIC$, whose parentheses are optional). All yield a value usable anywhere an expression is allowed.

Signature notation. The signatures in the tables below are the argument counts and types BR's compiler accepts — ck_alph_sysfn (command2.cpp) and ck_num_sysfn (command3.cpp) check every call against them, and a call outside them fails at LOAD with error 1042, system function parameter mismatch. BR types each argument as it compiles it, as a string if it can and as a number otherwise; an array argument has its elements' type.

  • No type tags: a $ suffix is a string argument and no suffix a number, without exception. A quoted literal is a string.
  • MAT x / MAT x$ is an array of that type; the MAT keyword is optional (see semantics), and [MAT]x$ says so in place.
  • [ ] encloses optional arguments. A bracket nested in another needs the one around it: F(a$[,b$[,c]]) takes one, two or three arguments, never a$ and c alone. A bracket written on a name — [^]s2$, [-]start — is text inside that argument, not an optional one.
  • x… is an argument that may be repeated: one or more of them.
  • a|a$ is an argument the compiler accepts as either type.
  • NAME[(…)] may also be written bare, with no parentheses.
  • A row listing several signatures for one name lists every form the compiler accepts.

Assignable pseudo-variables: CMDKEY, CURFLD, CURTAB, CURWINDOW, FKEY, PIC$. Each is set by calling it with LET and no = — LET FKEY(5), LET CURFLD(5) — never by assigning to it: LET FKEY=5 and LET FKEY(5)=1 both fail LOAD with 1026 (1030 for PIC$).

Semantics

  • String functions return strings (suffix $); numeric functions return numbers.
  • The array-processing functions (AIDX/DIDX, UDIM, SUM, SRCH, STR2MAT/MAT2STR) take array arguments and pair with assignment.
  • The MAT qualifier is optional. Wherever an argument must be an array, BR accepts either MAT name or a bare name, and reads the bare name as an array name. Both UDIM(MAT Y) and UDIM(Y) compile. Signatures in this spec and in dev/system-functions-catalog.md may show either spelling; neither is the required one.
  • The sole exception is AIDX/DIDX, which reject it — MAT X = AIDX(Y) compiles, MAT X = AIDX(MAT Y) does not. They are also functions only as an operand of a MAT primary, the right-hand side of a MAT assignment, and are not callable in an ordinary expression; see assignment for the <mat-rhs> production they belong to.
  • LEN(s$) returns the actual current length, not the DIM maximum.
  • Inverse pairs: CHR$↔ORD, HEX$↔UNHEX$, STR$↔VAL, ENCRYPT$↔DECRYPT$.
  • Several entries here query file/window or screen/keyboard state; they live in this index but belong operationally to 30-io-file and 20-io-screen — cross-linked in their tables below.
  • PROCIN / PROGRAM$ are value-returning here but their reference pages live under 70-commands/information.

Tables

String & character

Function Returns
CHR$(n) character for ASCII code n
ORD(s$) ASCII ordinate (0–255) of the first char of s$ (inverse of CHR$)
UPRC$(s$) / LWRC$(s$) upper / lower case
TRIM$(s$[,c$]) strip leading and trailing spaces (or the 1-char c$) — the same optional argument as LTRM$/RTRM$, read on the same line of strfunct.cpp for all three
LTRM$(s$[,c$]) / RTRM$(s$[,c$]) strip leading / trailing spaces (or the 1-char c$, nulls allowed)
LPAD$(s$,n[,pad$]) / RPAD$(s$,n[,pad$]) pad to length n (left / right), with pad$ if given and a space otherwise
RPT$(s$,n) s$ repeated n times
LEN(s$) actual current length
POS(s1$,[^]s2$[,[-]start]) position of s2$ in s1$ (0 if none); ^=case-insensitive (CONFIG SEARCH_CHAR); -start=search backward
SREP$(src$[,start],find$,repl$) string replace (each occurrence)
XLATE$(s$,table$[,start]) translate s$ through a 256-byte table$: each input char of ASCII value n is replaced by the (n+1)-th char of table$; chars past the table's length pass through unchanged. Optional start position. A table$ beginning STR2UTF/UTF2STR does UTF-8 conversion
LOGIN_NAME$[(name$)] current user's login name (3.83h+); with an argument it sets the name

Type conversion & formatting

Function Returns
STR$(n) number → string (plain)
VAL(s$) string → number
CNVRT$(spec$,n) number → string per a FORM format code (B BH BL D G GZ L N NZ PD PIC S ZD); enhanced STR$ (slower than a FORM) — see form-spec
CFORM$(form$) pre-compile a FORM string into a fast format variable (see note)
HEX$(s$) hex text → binary. s$ must be hex digits in pairs: HEX$("2B00") → 2 bytes (printer escapes; a printer translation starts this way). HEX$("ABC") (odd length) is invalid, and passing data that is not hex-digit text can abort the BR process rather than raise a trappable error — validate before calling
UNHEX$(s$) binary → hex text — the inverse. Renders arbitrary bytes readable: a 20-byte ENCRYPT$(…,"SHA-1") digest becomes its familiar 40-character hex string
PIC$[(sym$)] current currency symbol; with a 1-char sym$, sets it (persists until changed / BR exit; per-workstation)

CFORM$ caveat — output is an unreadable, machine/release-dependent internal format: never save it to a file or pass a format that references a variable (by length/decimals) into a library — the compiled form points to a dictionary slot, not a name, and may bind to the wrong variable.

Numeric & math

Function Returns
INT(n) integer part (truncates)
IP(n) / FP(n) integer part / fractional part (sign preserved: FP(-3.1)=-0.1)
CEIL(n) smallest integer ≥ n (always rounds up: CEIL(-5.1)=-5)
ROUND(n,d) round to d decimals
TRUNC(n) ⚠️ reserved but not implemented — parses (1 numeric arg) but returns a runtime bad-function error in the current BR source (trig() has no TRUNC case); there is no [,d] form. Use INT/IP to truncate
ABS(n) absolute value
SGN(n) sign of n: -1 (negative) / 0 (zero) / 1 (positive); a near-zero value can round to 0 per the RD config
SQR(n) square root
MOD(a,b) / REM(a,b) remainder (MOD(7,3) → 1; function only, no infix a MOD b; REM is an alias for MOD)
MAX(n,n…) / MIN(n,n…) largest / smallest of a numeric list
MAX$(s$,s$…) / MIN$(s$,s$…) largest / smallest string (by ASCII value)
SIN(n) COS(n) TAN(n) ATN(n) trig / arctangent (radians)
DEG(n) / RAD(n) ⚠️ reserved but not implemented — recognized keywords that return a runtime bad-function error (trig() has no DEG/RAD case); no radian↔degree conversion exists in the current source
LOG(n) / EXP(n) natural log / e^n
PI 3.14159265358979
INF largest representable number (1.0E+307); 1/INF = smallest
RND[(seed)] pseudo-random number in 0–1. Reseed from the clock with RANDOMIZE; LET RND(seed) sets a fixed seed for a repeatable sequence. Scale e.g. INT(RND*100+1)

‡ Accepted with one argument, and ignored. BR's arity checkers admit a single argument to TIME$, CURROW, CURCOL and PROCIN — ck_num_sysfn groups the last three under "optional 1 numeric", ck_alph_sysfn groups TIME$ under "0-1 parameters, optional string" — and the implementations never read it. strfunct.cpp's TIME_ arm is commented "return system time, no parms"; numfunct.cpp's CURROW/CURCOL return the field data and return; PROCIN carries a comment describing a setter it does not implement. So PRINT TIME$("hh:mm") compiles, runs and prints the ordinary time. This is the same failure mode as %, << and >> in expressions: the compiler agrees and the runtime has nothing to do. Recorded as ignored rather than as an optional parameter, because calling it a parameter is the more damaging error.

Date / time

Function Returns
DATE$ current date (yy/mm/dd)
TIME$ ‡ current time (hh:mm:ss)
DAYS(date|date$[,mask$]) day-count; Y2K-aware (BASEYEAR, auto century) 3.83+; dates from 1700 (3.90+)
DATE$([days][,"mask"]) format a day-count to a string ("day month, ccyy"; time masks 4.30+). Both arguments are optional and either may stand alone: DATE$("mm-dd-yy") formats today, DATE$(1) formats a day-count with the default mask
DATE([days][,"mask"]) numeric date sibling of DATE$ (for sorting; stores the days value); same optional arguments, and bare DATE is today
SQL_DATE$(d$[,fmt$]) / BR_DATE$(s$[,fmt$]) convert between a date string and the SQL timestamp value. SQL_DATE$ reads d$ using the format fmt$ (default: the current date format, as for DAYS) and returns a fixed-length SQL timestamp string; BR_DATE$ takes such a timestamp string and returns the date formatted by fmt$. A * in front of fmt$ also makes that format the session default, as in DATE$/DAYS. BR_DATE$ of a string that is not a timestamp (wrong length or prefix) raises a timestamp-conversion error; a bad fmt$ raises the date-format error. Used to move dates to and from ODBC/SQL columns

Date storage types DT/DL/DH are FORM field types — see 30-io-file/form-spec, not here. The currency/format-string behaviour interacts with PIC$ and OPTION INVP. Full mask reference: DATE$, DAYS, DATE.

Array-processing (used with MAT)

Function Returns
UDIM(MAT arr|MAT arr$[,dim]) current size of an array (or of dimension dim)
SUM(MAT arr) sum of all elements
SRCH(MAT arr,arg[,start]) / SRCH(MAT arr$,arg$[,start]) row of match [0/ -1(opt 56) if none]; ^ prefix = case-insensitive substring
AIDX(arr) / DIDX(arr) ascending / descending index array (original unchanged)
STR2MAT(s$,MAT a$[,[MAT]sep$[,flags$]]) split s$ → array; dynamically redimensions a$; returns the element count (delimiter/flags below)
MAT2STR(MAT a$,s$[,[MAT]sep$[,flags$]]) join array → s$ (delimiter/flags below)

STR2MAT / MAT2STR delimiter (sep$) and flags. sep$ is an ordinary user-supplied delimiter string — any string variable or literal (older wiki examples name the variable DLM$, but there is no DLM$ function) — or, as of 4.3, a MAT of delimiter strings ([MAT]sep$).

  • STR2MAT default (sep$ omitted): splits on any end-of-line run — \n\r, \r\n, \n, or \r — so multiple CSV/text rows in one string each become an element.
  • Empty delimiter sep$="": STR2MAT puts every character in its own element; MAT2STR concatenates with no separator.
  • Adjacent identical delimiters: STR2MAT honors each — all but the first produce an empty element (e.g. STR2MAT("Mary,,John",MAT c$,",") → Mary, ``, John).
  • MAT2STR default (sep$ omitted): CRLF on Windows / CR on Linux; the delimiter is placed after every element, including the last.
  • flags$ — an optional quote type Q / QUOTES / ' / " (case-insensitive), optionally followed by a trim flag :TRIM / :LTRM / :RTRM (the colon is used only when a quote type precedes it). On STR2MAT, quoting means a delimiter inside a quoted field is not a split point, and a doubled quote ("") inside a quoted field is one literal quote; on MAT2STR, each element is wrapped in the quote character.
  • Versions: MAT2STR introduced 4.20; STR2MAT CSV/XML/quote/MAT-delimiter enhancements added in 4.3.

File / drive query (I/O handlers — see 30-io-file)

FILE$[(n[,keyword$])] open file's name; with no arg = file of the most recent I/O error. A second keyword argument queries the open file ("HTTPINFO", "PAGE-URL", …)
FILE(n) status: -1 not open, 0 ok, 10/11 EOF in/out, 20/21 transmission err in/out
FILE(n,"WINDOW_RECT"|"USABLE_RECT"|"FONTSIZE"[,MAT a]) window/usable rect (x,y,w,h px) or char cell size
FILENUM file number of the most recent I/O error (= FILE$ with no arg)
FREESP(n) free bytes on the drive holding file n
EXISTS(file$) nonzero if file/PROC exists & readable (1=directory, >1=file) — test zero/nonzero only
BR_FILENAME$(os$) / OS_FILENAME$(br$) convert an OS path to a BR filename and back (4.18+; omit any leading colon — it would bypass the conversion)
KPS(n[,seg]) key start position; seg selects a split-key section; -1 if not open / no key / bad seg
LREC(n) / REC(n) last record / current record number
RLN(n[,newlen]) record length of open file n; the optional newlen resets it (EXTERNAL files only, and not above the OPEN RECL=)
VERSION(n[,ver]) the marked version number of INTERNAL file n (not the BR release); the optional ver sets it when the file is open OUTPUT (also settable with VERSION= on OPEN); a negative ver leaves the version as it is and empties the file's deleted record chain, which the next OUTPUT/OUTIN open that reuses records builds again (see OPTION 51)

LINESPP(<file number>) current lines per page of that print file: the LPP value of a BRConfig.sys PRINTER specification, else 66. It lets a report adapt to dot-matrix and laser printers on one system. A bracketed PRINTER substitution that carries an LPP changes it when it is printed: with PRINTER LPP 48 [SET48],"\Ep48", PRINT LINESPP(255) shows 66, then PRINT #255:"[SET48]" and PRINT LINESPP(255) shows 48
KLN(n[,seg]) / KREC(n) key length of keyed file n (seg selects a split-key section) / last record read in the index file, not the master; -1 if n is not open keyed (see keys-indexes)

Screen & keyboard query (see 20-io-screen)

Function Returns
KSTAT$[(n[,secs])] unprocessed keystrokes; with n, waits for n keys (secs timeout each). Fn keys = 2 chars; values are BR scancodes (UNHEX$ to read)
NXTFLD relative position of the next control to be occupied — no arguments, not assignable; pairs with FKEY to identify a clicked hot control. To set the next input field, attribute or exit keystroke, use CURFLD([field][,attr$][,fkey]) — see windows-cursor
NXTROW / NXTCOL row / col of the next cursor position (4.20+; mouse or keyboard; OPTION 59 for old CurCol)
NEXT next cursor position within a 2D control (4.20+; used in an INPUT FIELDS NEXT clause)
CURTAB[(win[,1])] active tabbed-window number; CURTAB(win,1) raises that tab (4.16+)
CURPOS cursor position within the field data when control returns to the program (4.20+); excludes untyped trailing spaces but counts invisible CRLF characters. Cursor row/col are CURROW/CURCOL — see windows-cursor
SCR_FREEZE / SCR_THAW (no arguments) suspend / resume remote (client-server) display repainting — freezeRemoteDisplay() / thawRemoteDisplay() in the source; each returns 0 (batch updates, then thaw to repaint once)
CURROW ‡ / CURCOL ‡ cursor row / column when input ended (see windows-cursor)
CURFLD[(field[,attr$[,fkey]])] / CURFLD(field,row|cell) / CURFLD(field$) the 1-based field the cursor was on after the last INPUT FIELDS; with arguments it sets the next input's starting field, added attributes and a replayed fkey, or positions into a 2-D control's row/cell (see windows-cursor). The compiler also accepts a single string argument, to no documented effect
CURWINDOW[(n)] the focused PARENT=NONE window (-1 if none); n raises that window
CMDKEY[(n)] / FKEY[(n)] the key that ended input (0 = Enter; -1 before the first input); FKEY is the richer successor, also set by controls, buttons and hot windows. LET CMDKEY(x) / LET FKEY(x) preset them (see windows-cursor)
MENU[(n)] / MENU$[(n)] MENU is the subscript, MENU$ the data string, of a native-menu item. With no argument they refer to the item most recently selected; MENU$(n) gives the data of item n (1-based) of the terminal window's menu, and an index that is not a live item returns the empty string. MENU(n) as a statement-style call sets which item counts as last selected (item n). See controls

System / information

Function Returns
ERR the number of the most recent error. Used in an error routine (ON ERROR GOTO 99900 then PRINT "Unexpected error";ERR;"at line";LINE) and in procedures to see whether a command worked (PROCERR RETURN, the command, PROCERR STOP, SKIP DONE IF ERR<>0). It is set to zero by RUN, PROCERR RETURN, CLEAR, CLEAR ALL and any command that clears memory. It is not set (a) when ON error … IGNORE (or the default) ignores that condition, (b) for error 4273 (topic not found in the help file), so that a failed HELP$ inside an error routine cannot spoil RETRY or CONTINUE, and (c) by an error in an immediate statement keyed at the keyboard. With PROCERR RETURN in a procedure the error is skipped but ERR is still set. An error produced by a string run with a line-numbered EXECUTE sets it too
LINE the line number of the most recent error (not the line now running); -1 when there has been none, after RUN, PROCERR RETURN, CLEAR or CLEAR ALL, and for an error in a procedure while PROCERR RETURN is in effect. It is unchanged in the same cases as ERR, including 4273. With PROCERR RETURN, a syntax error during LOAD … SOURCE gives the number of the previous line (the current one was not accepted) and control returns to the procedure
CNT the number of data items successfully processed by the last I/O statement (MAT A(CNT) sizes an array to what was read). After an I/O error it localises the fault: with READ #2,USING 520: MAT PAYTYPE$,FLAG$,MAT AMT and 52-element arrays, a conversion error (0726) with CNT = 52 means the first 52 items read and the 53rd is the bad one. For an error in a field-definition array of INPUT FIELDS, PRINT FIELDS or RINPUT FIELDS, it is the number of the last element processed. If the current error was not an I/O error, CNT describes an earlier one
BRERR$([code]) the description of a BR error code — what ERR is to the number (e.g. BRERR$(682); 4.3+). Bare describes the last error
ENV$(name$[,MAT cfg$|MAT cfg[,arg|arg$]]) environment / status interrogation (4.30+) — see environment
CODE the return code the last program set, with STOP n or END n (a bare STOP or END sets 0); 0 until something sets one, and cleared again by LOAD, CHAIN and CLEAR (RUN leaves it). Not a procedure's return value: BR has no EXIT n command
PROCIN ‡ non-zero while a procedure is feeding input (0 = keyboard)
WSID$ this session's workstation ID
USERID$ BR licensee name
SERIAL serial number of this BR software copy
SESSION$ this session's ID — WSID$ (3–4 digits) followed by a 1-digit session number 1–9 (e.g. 011, 012)
PROCLVL current procedure nesting level: 0 at the keyboard or when no procedure is running, 1 inside a procedure started from the keyboard, and one more for each procedure nested inside it. The deepest level is 9; a tenth raises the too-many-active-procedures error
TIMER seconds since the Unix epoch (1970-01-01 UTC) as a 5-decimal real; use two readings to time a section (accuracy follows the OS clock)
SETENV(name$[,value$|value]) set a BR session environment variable (read back with ENV$; function form of CONFIG SETENV). 2 args = name$,value$; 1 arg = a single NAME=VALUE directive string
VARIABLE$ name of the variable that failed in the last I/O statement (for debugging / HELP$ topics); not set for field-spec errors 850–890 or for calculated expressions
WBVERSION$ the running BR version, as a string
WBPLATFORM$ the platform string; returns WINDOWS on a unix/aix/linux client-server run when CONFIG SHELL DEFAULT CLIENT is set (so client-side shell/print behavior is used)
SYSERR / SYSERR$[(n)] the underlying OS error number / its description (companion to ERR/BRERR$); SYSERR$(n) describes that code rather than the last — see 90-reference/error-codes
SHIFT[(n)] Deprecated — no longer offered as a function. Always returns 0 — a legacy System/23-compatibility no-op (any argument is accepted and ignored)
MSG$("text") display text in the 2nd box of the command console
MSG(action$[,arg|arg$…]) twenty-five actions (Windows / Client-Server): MSG("send",keys$) types into this session — the keys go into BR's own buffer, so they reach no other window and need no focus — with special keys in pipes, e.g. `"
SLEEP(seconds) pause; fractional seconds, ms resolution (3.83h+)
SPAWN_RESTRICTED(command$[,config$[,wait[,label$]]]) BR 5.0. Start a disposable restricted session on this WSID — the next free session number — running command$ as its startup command, typically PROC <file>. config$ defaults to this session's. No wait or 0 returns the new process id at once; a wait in seconds yields as SLEEP does and returns the session's exit code. label$ says what the session is for, and opens its audit log. See SPAWN_RESTRICTED for the errors and the ordering that makes the restriction hold
HELP$([*]kw$[,mark|anchor$[,"BROWSE"]]) enter HELP mode / show a topic (see windows-cursor §help). The second argument is a numeric mark for the .wbh help (OPTION 85 ON) or a string anchor$ for the br_tree help (OPTION 85 OFF, the default); the compiler accepts either, and the one that does not suit OPTION 85 raises error 9505 when it runs. With OPTION 85 off, HELP$(folder$,anchor$) returns where in br_tree the topic is, and a third argument "BROWSE" also shows it as the help key does: in the person's web browser when br_tree2 is found, else on the console. Any other third argument is error 410; a third argument with OPTION 85 on is error 9505
PROGRAM$ full path of the loaded program — handy in shared error routines (see information)
DEBUG_STR(level,str$) write str$ to the debug log at level (4.3+; see information). In a restricted session it is written as Program note: <str$>, on one line, at level 5 or above
PRINTER_LIST(MAT a$) redimensions a$ to the active Windows printer names (see information)
NEWPAGE a char that form-feeds the printer / clears the screen and zeroes the line counter (LINES/KREC); PRINT #255: NEWPAGE no longer emits a trailing CR — avoid it immediately before TAB(x) in an unformatted PRINT
BELL / TAB(x) sound the tone / tab to column x within a PRINT list

Message box

Function Returns
MSGBOX(prompt$[,title$[,buttons$[,icon$]]]) the chosen button, also in CNT

MSGBOX shows the platform's own message box and returns the chosen button in CNT (and as the function value). Only prompt$ is required. Force a line break in the text with CHR$(13) or HEX$("0D0A") (two in a row = a blank line).

00060 IF MSGBOX('Are the labels aligned?','Check Printer','Yn','Qst')><2 THEN GOTO ALIGN

buttons$, which is not case sensitive except for choosing the default button:

buttons$ Buttons, left to right Default (Enter) button
OK (the default) OK OK
OKC OK, Cancel OK
YN Yes, No the capital letter: Yn Yes, yN No
YNC Yes, No, Cancel the same as YN
YNAC Yes, No, All, Cancel the capital letter: ynaC Cancel, yNac No, otherwise Yes. All cannot be the default

^ anywhere in buttons$ ("YN^", "^" for OK) adds a Don't ask again checkbox. A ticked checkbox adds 10 to the answer.

Answer Returns With Don't ask again ticked
OK 1 11
Yes 2 12
No 3 13
Cancel 4 14
All 5 15

0 is returned on an error (rare). A program that does not use ^ never sees a value over 5.

Escape and the close box answer Cancel on a box that has a Cancel button, and OK on the OK box. A YN box has neither, so the operator must choose Yes or No.

Ctrl-A on the box is an interrupt, not an answer. The box closes, the program halts with ATTN at the MSGBOX (an ON ATTN handler takes it as usual), and GO runs the MSGBOX again, showing the box anew.

icon$: the icon is the platform's own.

icon$ Windows shows Use it for
INF (the default) a blue circle with a white i information
ERR a red circle with a white X an error
EXCL a yellow triangle with a black ! a warning
QST no icon a question

QST shows no icon on Windows because the Windows task dialog, which BR uses for message boxes, has none for questions; Microsoft's guidance is that routine questions carry no icon. Linux shows the desktop theme's information, error, warning and question icons for the four values.
