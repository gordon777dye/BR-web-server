FnSnap function packs

FnSnap is a shipped collection of ready-made FN… library functions (dialogs, screen helpers, printing/PCL, bar codes, dates, files, arrays, window maintenance). Link them with the library facility like any library function and call FNINIT once at program start. This page is a navigational index; each function's full signature, parameters and notes live in the per-area FnSnap__* pages linked below.

Semantics

  • Initialize with LET FNINIT(; SYSDIR$, SYS$) before using FnSnap functions; LIBRARY "fnsnap": FN… lists the ones you call.
  • Functions are grouped into the areas below; a few appear in more than one pack (e.g. FNOPEN, FNPROGRESS, FNDIALOG).
  • Get it: fnsnap.dll ships in fnsnap.zip (ftp.brulescorp.com /Brg_pub/Zip/ — names are case-sensitive); the zip includes fnsnap.pdf with the same reference. Every entry is a library function, linked via LIBRARY. (Project lead: George Tisdale.)

Obsolete

Deprecated FnSnap functions kept for legacy programs are catalogued in FnSnap__FNSNAP_Obsolete_functions — avoid in new code.

Examples

00100 LIBRARY "fnsnap": FNINIT, FNDIALOG, FNCODE3OF9
00110 LET FNINIT
00120 LET RC = FNDIALOG("Save changes?")          ! dialog box
00130 PRINT #255: FNCODE3OF9(INVNR$)              ! 3-of-9 bar code
