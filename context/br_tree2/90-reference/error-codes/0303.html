0303

Error: 0303

Description: Illegal pass by reference to user defined function

BR 5 message: cannot pass a literal by reference

Details: Attempted to pass a literal to a user-defined function when the function was expecting a variable. Pass a variable or remove the ampersand (&) from the function's Def statement.
