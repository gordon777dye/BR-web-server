0633

Error: 0633

Description: BTREE2 index made before 5.01: rebuild it with INDEX ... REPLACE

Details: - A key was added, deleted or changed in a Btree2 index made by a release before 5.01 (version 2). BR 5.01 reads such an index but does not update it, because it locks a Btree2 index record by record, and needs room in each index record that a version 2 index does not have.

  • Rebuild the index with INDEX ... REPLACE, or with INDEX ... REORG, which rebuilds a version 2 index from the master file. The rebuilt index is version 3.
  • Releases before 5.01 refuse a version 3 index (error 4124), so upgrade every engine that shares the files at the same time.
