0716

Error: 0716

Description: PRINT to an HTTP server file before a request was read Available as of BR! 4.30.

Setup documentation: HTTP_SERVER.md §2.5 Writing a response

Write after a request is current.

Fix: Read with LINPUT first, and print only in answer to a request.
