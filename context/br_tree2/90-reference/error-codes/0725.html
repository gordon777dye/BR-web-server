0725

Error: 0725

Description: Field too small

BR 5 message: field too small - data mapping error in RINPUT

Details: The output value for a RINPUT FIELDS statement is larger than the field size. Increase the field size or make sure that the variables to be printed will fit into their corresponding field definitions.
