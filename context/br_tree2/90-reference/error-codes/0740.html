0740

Error: 0740

Description: This BR already has an HTTP=SERVER file open Available as of BR! 4.30.

Setup documentation: HTTP_SERVER.md §2.1 Statements

Only one channel may hold HTTP=SERVER at a time in one BR: a second OPEN gives error 740.

Fix: Use the channel already open, or CLOSE it first.
