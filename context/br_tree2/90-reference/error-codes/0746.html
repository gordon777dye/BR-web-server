0746

Error: 0746

Description: No current HTTP request - read one with LINPUT first Available as of BR! 4.30.

Setup documentation: HTTP_SERVER.md §2.3 FILE$ inquiries

All of these refer to the current request, the one the last read returned.

Fix: Call FILE$ after a LINPUT has returned a request, or error 4270.
