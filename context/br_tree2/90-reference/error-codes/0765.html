0765

Error: 0765

Description: HTTP=SERVER must be opened OUTIN

Name: BREHTTPNOTOUTIN

Details: HTTP=SERVER was opened INPUT or OUTPUT. The channel has to read requests and write responses.

Setup documentation: HTTP_SERVER.md §2.1 Statements

The file must be DISPLAY, opened OUTIN: it reads requests and writes their responses.

Fix: Open it DISPLAY, OUTIN.

Available as of BR! 5.02.
