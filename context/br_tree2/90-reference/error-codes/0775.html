0775

Error: 0775

Description: BIND= is not a valid address

Name: BREHTTPCFGBIND

Details: The address has the wrong form, or a host name does not resolve. Raised by the OPEN.

SYSERR$: The address.

Setup documentation: HTTP_SERVER.md §1 Configuration directives

Listen on this one address of this machine (IPv4, or IPv6 without brackets), or a host name that resolves to one, instead of on all of them.

Fix: Correct the address, such as BIND=127.0.0.1.

Available as of BR! 5.02.
