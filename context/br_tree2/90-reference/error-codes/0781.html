0781

Error: 0781

Description: HTTP URL_BASE= names a file, not a folder

Name: BREHTTPURLBASEFILE

SYSERR$: The path.

Setup documentation: HTTP_SERVER.md §1 Configuration directives

It must exist and be a folder: a wrong URL_BASE= fails the OPEN.

Fix: Name the folder that holds the site.
