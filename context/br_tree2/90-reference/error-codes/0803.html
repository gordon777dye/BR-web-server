0803

Error: 0803

Description: Missing format spec

BR 5 message: missing data specifications in FORM data item

Details: FORM statements used for output of data items must have at least one data format specifier. For example, FORM POS 1 is invalid for output of data items. Change the FORM statement so that it includes at least one format specification.
