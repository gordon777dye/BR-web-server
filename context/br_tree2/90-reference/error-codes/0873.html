0873

Error: 0873

Description: Partial dictionary element sent to 2D Control

BR 5 message: invalid attempt to split array variable with grid, list or other control using multiple values

Details: Partial dictionary element sent to 2D control. Sub-arrays are not allowed as receptacles of 2D controls.
