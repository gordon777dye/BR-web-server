0880

Error: 0880

Description: Invalid user level specified

BR 5 message: bad field help level

Details: Invalid user level specified in a help string. (see Help Facility) Make sure that the user level is 1, 2 or 3. In Business Rules! 4.2 user level 4 is supported.
