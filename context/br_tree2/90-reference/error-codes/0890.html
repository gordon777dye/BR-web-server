0890

Error: 0890

Description: Bad attribute keyword following ^ symbol

One cause for error 890 is specifying ENTER-CRLFS instead of ENTER_CRLFS in BR 4.2j and higher.

The keyword was introduced in 4.2ia as ENTER-CRLFS and then changed to ENTER_CRLFS in 4.2j.
