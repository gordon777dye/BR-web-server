1000

Error: 1000

Description: Unidentified source remaining

Details: - Unidentified source remaining. This error sometimes occurs when Working with converted files.

  • Attempt to use a variable which includes a space.
  • double and (i.e.: if x=1 and and y=2 then print z) #Go to the error-causing line and either delete whatever garbage characters are present or retype the entire line.
  • Use only valid variable names.
  • removed the extra and (i.e.: if x=1 and y=2 then print z)
