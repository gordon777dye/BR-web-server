1009

Error: 1009

Description: Invalid regular expression

Details: The /.../ pattern of a SEARCH command is not a valid regular expression (ECMAScript syntax, or HELP COMMANDS REGEX; its Not supported list has the constructs from other regex languages that give this error), for example /(/, which opens a group and never closes it. Correct the expression, or search for the text as a literal by quoting it: SEARCH "(" file. At the console the cursor returns to the fault where it can be found - an unmatched ( or ), an unclosed [, a bad {, a *, + or ? with nothing to repeat, a range such as [z-a] - and otherwise to the start of the pattern. New in BR 5.03.
