1036

Error: 1036

Description: Illegal string data

BR 5 message: invalid numeric expression

Details: - String data occurs in a numeric expression.

  • some_string$=some_number #String expressions may contain only string data; numeric expressions may contain only numeric data. Fix the error-causing expression.
  • some_string$=str$(some_number)
