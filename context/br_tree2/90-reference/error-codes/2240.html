2240

Error: 2240

Description: Incorrect Business Rules Release

BR 5 message: release level error

Details: A LOAD or CHAIN COMMAND was issued for a program that does not match this release of BR (it is either earlier or later than the release in use). Save the program in source, reload it, and replace it
