4138

Error: 4138

Description: Can't rename from one file system to another, or between client and server

Details: RENAME never copies. Its to must be on the same drive, share or mounted file system as its from, and both on the client (@:) or both on the server. Otherwise the rename is refused and both names are left as they are; use COPY and then FREE to move a file there. See RENAME.
