4148

Error: 4148

Description: File sharing violation

Details: Violation of file sharing rules. Attempt to access a file that is in use and cannot be shared.
Most likely one of the following occurred:

  • Some other computer has the file open without sharing it.

  • You need non-shared access to a file and another computer has it opened.

  • The operating system (or another program) has locked the file.

  • Opening an indexed file where the name and the kfname the same #Check to see that the correct Shr parameters were specified in the Open statement. If so, change the program so that it does not violate the file-sharing rules or wait for release of the file in use.

  • Use Status Locks to determine which workstation has the file locked.

  • Possibly an anti-virus program, or any number of other programs.

  • correct the mistake

  • Microsoft - Help and Support - Configuring opportunistic locking in Windows
