4501

Error: 4501

Description: Invalid shell call, or OS function failure

BR 5 message: bad OS function

Details: Invalid function during Win32 shell call. This has been known to happen during EXECUTE '*Status Files >Tempfile' (In this case, there was a problem with the drive)
