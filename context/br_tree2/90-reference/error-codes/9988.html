9988

Error: 9988

Description: DEPRECATED ERROR as of 4.3: Source line too large

BR 5 message: source line greater than 800 bytes

Details: Source line is greater than 800 bytes. Save the program as source and reload it as source. If the error persists, call BRC for help.
