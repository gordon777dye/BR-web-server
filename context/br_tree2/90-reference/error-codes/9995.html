9995

Error: 9995

Description: Deprecated error as of 4.3: RPN stack failure. SysErr and it always seems to want to kick you out of BR!

BR 5 message: RPN stack failure

Details: - One thing that will cause it is doing an exists(x$) when x$ has a length of 199.

  • CURFLD(14) where there are less than 14 available fields.
  • in BR 4.0 an exists of apx 70 characters or more would cause this error. #Trim it or copy it to a location with a shorter path name. You can probably cause the error with any path with a length more than the maximum length path that BR! allows!
  • Reduce the 14 to an appropriate number
  • reduce the path to 66 (?) or less characters.
