4.18J

OPTION 61 will prevent automatic mapping of drives that are referenced by the second parameter of a drive statement and will produce a regular 4 digit BR error when any drive references are made to unmapped drives.

An OPTION 64 controls the client server timeout duration. e.g. OPTION 64 20 ! wait 20 seconds before timing out CS connection

SAVE will now always provide a confirmation dialog before overwriting a file.
