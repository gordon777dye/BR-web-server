Business Rules! Documentation — Master Index

Reorganized for segmented application development. Configuration/platform concerns are kept separate from coding specifications. Each folder has its own _index.md.

Top-level map

  • 00-configuration/ (23 docs) — Platform, deployment and environment configuration. Not coding — nothing here is needed to reason about program logic.
  • 10-language/ (21 docs) — In-memory data operations — the core coding language: syntax, flow control, and data manipulation.
  • 20-io-screen/ (17 docs) — Screen input/output authoring: fields, attributes, controls and windows.
  • 30-io-file/ (18 docs) — File input/output authoring: statements, form specs, keys/indexes and the file model.
  • 40-io-printing/ (7 docs) — Printing authoring (coding side only; spool/printer config lives under 00-configuration).
  • 50-libraries/ (27 docs) — Reusable library facility and the shipped function packs.
  • 60-integration/ (7 docs) — Web & data-exchange integration — JSON/data store and BR as a web server.
  • 70-commands/ (14 docs) — Executive/console commands. Integral to coding because they are runnable from program code via EXECUTE "<cmd>".
  • 90-reference/ (868 docs) — Lookup-only reference material — not authoring specifications.
